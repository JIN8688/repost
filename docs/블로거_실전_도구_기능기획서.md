## 🔧 Core 기능 - 글쓰기 도구

### 1. 실시간 텍스트 분석기 ⭐⭐⭐⭐⭐

#### 기능 설명
```
블로거가 글을 복사 → Repost에 붙여넣기
→ 즉시 분석 결과 표시
```

#### 분석 항목

**1.1 글자수 카운터**
```
📊 글자수 분석

전체: 1,247자 ✅ (권장: 800-2,000자)
본문: 1,180자
제목: 67자 (권장: 20-50자)

────────────────────────
읽는 시간: 약 2분 30초
```

**1.2 키워드 밀도 체크** 🔥
```
🔍 키워드 밀도 분석

"맛집" 18회 (1.4%) ⚠️ 너무 많음! (권장: 0.5-1%)
→ 5-7회로 줄이세요

"추천" 6회 (0.5%) ✅ 적정
"서울" 4회 (0.3%) ✅ 적정
"데이트" 2회 (0.2%) 💡 조금 더 추가 가능

────────────────────────
📌 개선 제안:
"맛집" 대신 사용할 수 있는 단어:
→ 레스토랑, 식당, 음식점, 먹거리
```

**1.3 중복 표현 감지**
```
🔄 중복 표현 체크

"정말" 12회 반복 ⚠️
→ 대체어: 진짜, 굉장히, 아주, 매우

"~것 같아요" 8회 반복 ⚠️
→ 단정적 표현으로 변경 추천

같은 문장 구조 5회 반복 감지:
"[장소]에 가봤는데..." 패턴
→ 다양한 시작으로 변경 추천
```

**1.4 가독성 점수**
```
📖 가독성 분석

종합 점수: 72/100 ✅

문장 길이: 양호 (평균 42자)
단락 길이: 주의 (평균 8줄) ⚠️
→ 4-5줄로 나누는 것 추천

줄바꿈: 적절함 ✅
띄어쓰기: 2곳 오류 감지 ⚠️
```

#### 개발 사양
```javascript
// 입력
textarea: "사용자가 쓴 글 전체"

// 분석
- 글자수 카운트 (공백 포함/제외)
- 키워드 추출 (형태소 분석)
- 키워드 빈도 계산
- 문장 길이 분석
- 단락 구조 분석
- 중복 패턴 감지 (정규식)

// 출력
- 시각적 대시보드
- 개선 제안 리스트
- 한눈에 보는 점수
```

**개발 난이도**: 중  
**예상 시간**: 12-16시간  
**유료 전환 기여도**: 🔥🔥🔥🔥🔥 (80%)

❌ 구체성 부족
❌ 혜택이 명시되지 않음

개선된 제목:
"강남 맛집 TOP 7 | 인스타 감성 + 가성비 甲"
